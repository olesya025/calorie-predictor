# Calorie Predictor: нейросеть для предсказания калорийности блюд

Проект по Deep Learning: мультимодальная нейросеть, которая по фотографии блюда и списку ингредиентов предсказывает его калорийность.

## Задача

Дано:

- 3262 блюда с фотографиями и описанием ингредиентов
- Целевая переменная — `total_calories` (ккал)
- Готовое разбиение на train/test: 2755 / 507

Цель: построить модель с MAE < 50 ккал на тестовой выборке.

## Данные

Датасет содержит:

- `dish.csv` — 3262 записи: `dish_id`, `total_calories`, `total_mass`, `ingredients`, `split`
- `ingredients.csv` — 555 записей: справочник ингредиентов
- `images/` — 3490 директорий с фотографиями блюд (`rgb.png`)

Ингредиенты в `dish.csv` хранятся в виде технических ID (`ingr_0000000508`). На этапе подготовки они заменены на названия из справочника — например, `soy sauce, garlic, white rice`.

## Подход

Архитектура: мультимодальная регрессия.

- Image-энкодер: `efficientnet_b0` из `timm`, предобученный на ImageNet
- Text-энкодер: `cointegrated/rubert-tiny2` из `transformers`
- Проекционные слои приводят эмбеддинги обеих модальностей к размеру 512
- Fusion: конкатенация эмбеддингов
- Classifier: полносвязная голова с одним выходным нейроном (без активации)

Обучение:

- Лосс: `nn.L1Loss()` — оптимизирует MAE напрямую
- Оптимизатор: `AdamW` с разными learning rate для энкодеров и головы
- Аугментации: `HorizontalFlip`, `RandomBrightnessContrast`, нормализация по статистикам ImageNet
- Чекпоинт с лучшим MAE на тесте сохраняется на Google Drive

## Результаты

Финальный MAE на тестовой выборке: **60.62 ккал**.

Анализ ошибок показал системную причину: модель не получает на вход массу порции, хотя в датасете она коррелирует с калорийностью на уровне 0.76 (Пирсон) и 0.78 (Спирмен). Без этого признака модель систематически недооценивает калорийные блюда. Все 5 самых тяжёлых ошибок — это недооценка на 40–55%, что подтверждает гипотезу.

Топ-5 ошибок:

| Блюдо | Реально | Предсказано | Ошибка | Масса | Ингредиенты |
|---|---|---|---|---|---|
| dish_1565811139 | 902 | 392 | 510 | 416 г | курица, козий сыр, оливковое масло, овощи |
| dish_1558549806 | 782 | 359 | 423 | 203 г | миндаль, белый рис, шпинат |
| dish_1563478751 | 950 | 571 | 379 | 545 г | паста, говядина, сливки, сметана, вино |
| dish_1558630325 | 752 | 378 | 373 | 269 г | яблоко, салат, миндаль |
| dish_1558720236 | 888 | 522 | 366 | 407 г | яблоко, морковь, цветная капуста, миндаль |

Все 5 ошибок — недооценка. Модель занижает предсказания на 40–55% на калорийных блюдах.

## Анализ ошибок

1. **Отсутствие массы порции на входе.** Модель не может отличить маленькую порцию от большой при одинаковом составе.
2. **Длинный правый хвост распределения.** Блюд с калорийностью выше 700 ккал всего 3.8% — модель «недоучивается» на выбросах.
3. **Скрытые калорийные ингредиенты.** Миндаль, оливковое масло, сливки, сметана, сыр — калорийны, но в тексте выглядят как обычные ингредиенты.
4. **Ложные ассоциации с «лёгкими» блюдами.** Овощи в списке — модель думает «салат» и занижает калорийность.

## Возможные улучшения

- Добавить массу порции как входной признак (по условию задачи не подаётся)
- Взвешивать лосс, чтобы ошибки на калорийных блюдах вносили больший вклад
- Более сильный image-энкодер (`convnext_tiny`, `efficientnet_b3`)
- Cosine learning rate scheduler и early stopping
- Усреднение нескольких чекпоинтов (snapshot ensemble)
- Oversampling редких калорийных блюд

## Как запустить

1. Открыть `notebook.ipynb` в Google Colab с T4 GPU
2. Выполнить ячейки по порядку: подготовка данных → EDA → пайплайн → обучение → валидация
3. Данные скачиваются автоматически с Яндекс Диска по публичной ссылке
4. Чекпоинт обученной модели загружается с Google Drive

Зависимости: `albumentations`, `transformers`, `timm`, `torchmetrics`.
